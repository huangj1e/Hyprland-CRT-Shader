# Security Policy

## Supported versions

Only the latest released version is actively supported.

## Reporting a vulnerability

Do not include sensitive system information in a public issue. Contact the maintainer privately through the security-reporting mechanism provided by the eventual project hosting page.

This project consists of a GLSL screen shader, configuration examples, and a local toggle script. Reports concerning unsafe shell behavior, package integrity, unexpected file modification, or compositor denial of service are in scope.
